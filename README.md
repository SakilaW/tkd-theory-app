# tkd-theory-app

A static Taekwon-Do theory study app. Open `index.html` to set up and take a quiz, `progress.html` to review locally saved progress, or `question-bank.html` to search the question bank.

The pages share question data in `data.js`, common styling in `styles.css`, and browser storage helpers in `shared.js`. Quiz progress is stored in this browser's local storage.
